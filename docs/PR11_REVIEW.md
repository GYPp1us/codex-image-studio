# PR #11 审阅修正

本次接受已完成工作保留、图块诊断、自动恢复、参数继承和预算相关意见，并处理同模块的性能与重复定义问题。没有执行生产任务或真实模型调用。

## 检查点与诊断

- v4 已接受且未落后于返回图的配准检查点继续有效，避免重新配准清除已经通过的融合与审核。v4 拒绝记录不会变成已接受记录，输出变化仍使旧检查点失效。
- 失败诊断优先读取有效配准记录，按 `accepted` 和 `method` 解释画幅坐标回退。没有检查点才执行与引擎一致的配准逻辑，不强行索取 SIFT 内点字段。诊断缓存指纹升级。
- 合成前按图块核心区域，对所有相邻块的真实 valid mask 求并集；缺口报告所属图块编号，工作流只重绘该块。合成后的覆盖检查同样携带块号，按图块限制重试次数，最终仍要求零空洞。
- 局部修复完成后清除原插值标记，有局部修复记录的块不再进入普通插值。检查点验收与预算记账分开，记账存储失败不删除已经返回的 AI 图片。

## 本地插值与预算

- 插值失败或其配准失败时，该块转入模型路径；取消仍直接传播。本地配准失败不占用模型生成尝试额度，包括 `max_attempts=1`。
- 插值在进程内的独立两路队列执行，不等待全局融合锁。取消时等待已经开始的本地计算退出，避免遗留后台写入。
- 裁块分类按输入 SHA 和分类版本缓存；已有 AI 检查点不重新分类。插值可复用同 SHA 的分类结论，输入变化会重新检查。
- 后续级的修复预算只加入真正需要模型处理的块；全平滑级保持零生成和零视觉审核。明确选中平滑块重绘时计入模型路径，首次重绘不会重复计费预算。

## 生成参数

- 快捷项只保存用户点选的字段。未覆盖字段继续继承全局设置；没有覆盖时请求不携带 `image_backend`，有覆盖时服务端用 `exclude_unset` 合并到提交时的设置快照。
- 「再抽一张」携带原生图任务冻结的图片通道配置，避免悄悄改用当前默认模型。
- 读取旧固定项时跳过已失效的数据，新提交继续严格校验。图片模型、质量和通道从实际模型定义推导，尺寸与超分倍率共用类型域，前端图片模型共用一个列表。
- 清除不再使用的版本导入与诊断路径变量，本地插值检查点校验共用函数。
