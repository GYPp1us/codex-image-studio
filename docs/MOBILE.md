# 独立移动应用

工作台同时提供 Android 安装包和 Web App，两者连接同一服务端、账户、任务和图库。生图仍由 LA 上的官方 Codex CLI 执行；手机锁屏或关闭应用不会取消已提交任务。

## 安装

- Android 10 及以上：打开工作台的「安装应用」，下载安装包，允许当前浏览器安装此应用。首次打开使用工作台用户名和密码登录；无需重新授权服务器上的 Codex 订阅。
- iPhone：用 Safari 打开工作台，在分享菜单选择「添加到主屏幕」。
- Android 浏览器：也可以在浏览器菜单选择「安装应用」或「添加到主屏幕」，使用 Web App。

Android 版本具有独立图标、窗口和会话，支持竖屏及按系统旋转策略切换的横屏工作区。系统图片选择器支持多图导入，原图直接从内建缓存保存到 `Downloads/ImageStudio`。应用需要联网，不包含本地生图模型。

## 竖屏交互

底部为创作、作品、任务、模板四个入口。创作页切换生成 / 超分，参数从生成按钮旁的摘要打开。提交后保留草稿并原地反馈；参考图库、作品和上传统一放在图片选择面板。头像菜单提供设置、最近删除、安装应用和退出登录。设置整合账户与调用设置，按分区自动保存。作品只展示结果，任务按批次分组并用一条分段进度条汇总。

参考图选择使用独立面板，底部加入按钮固定，主体每次加载 40 张，接近底部自动续载并提供重试。角标勾选与主体放大分开，放大页仅提供本图选择，返回保留选择与滚动位置。已加入的图点按放大，按住约 420 ms 后以主题色轮廓浮起，只允许横向拖动排序；激活前保留原生滚动，取消或旋转恢复原顺序。键盘可用 Alt 加左右键。创作与模板编辑共用这些操作；取消选择页不改草稿。空提示词的模板详情省略提示词框。载入模板保留已有正文，参考图按已有顺序去重补充，最多 8 张；其他生成参数应用模板设置。

账户菜单和设置提供自定义头像，可拖动定位并用滑杆缩放，确认后保存圆框内的内容，也可恢复默认。头像独立于图片资产，存储为 512×512 WebP，受服务器存储限额约束；支持 12 MB、4000 万像素以内的 PNG、JPEG、WebP。头像读取与修改仍需工作台登录，修改使用现有 CSRF 保护，不退出其他设备。

「外观」提供跟随系统、浅色、暗色及预设 / 自定义主题色，选择后即时预览并自动保存。强调色的文字与背景经过对比度调整，页面首次绘制前恢复上次外观。查看器始终保持深色背景；系统外观变化不会提前恢复查看器顶部配色，关闭后使用当前主题。Android APK 的系统栏同步沿用原生通道，无需为这些网页功能重新安装 APK。

「帮我润色」默认关闭。开启后使用独立调用提示词，由当前模型设计构图、层次、光线、配色和风格标签，再调用生图工具。原始正文仍保存在任务中，完整调用和模型输出可在记录、日志中查看。两套调用提示词均可在调用设置中编辑。

「图像尺寸」支持自动、1K、2K、4K 长边。该值传给模型作为原生生图要求。内置工具不提供强制像素参数，因此并不保证输出严格等于所选像素；系统保留真实产物，不自动放大伪装分辨率。图片详情显示实际宽高。润色、尺寸、画幅等设置随模板保存，并随任务固定，重试使用原任务配置。

任务轮询通过 DOM 差异更新，保留未变化的图片节点，避免每次轮询重新创建缩略图。图片与图集删除后进入「最近删除」，可恢复；底层文件和历史引用继续保留，不会打断模板或任务重试。图集删除不取消进行中的任务；再次通过同一模板提交会重新显示该图集。

点图片直接打开全屏查看器，先显示已解码的缩略图，高清预览解码完成后再替换，打开和切图都不会出现空白帧。双指缩放、单指平移（松手后带惯性滑行），双击在手指位置平滑放大到 2–3 倍、再次双击回到适应画面；适应大小时可左右滑动切图、下滑关闭，更多菜单提供 100% 原生像素。单击切换操作栏会等待双击判定（约 260ms）。底栏集中图片操作，ⓘ 面板展示名称、标签、提示词与来源；速改输入框可提交一句修改要求。在查看器里输入速改或重绘要求时，键盘和输入面板浮在图片上方：图片的缩放和屏幕位置保持不变，输入法候选栏改变键盘高度也不会移动图片和选区；确认输入法候选的回车不会提交表单。局部重绘可框选最多 6 个不重叠区域，各区域单独或共用要求，并行处理后合成一张图。详见 [局部重绘](LOCAL_EDIT.md)。

列表、查看器、编辑模式和面板统一使用 history 返回栈，系统返回或关闭每次退出一层。通用面板支持拖动关闭；系统或设置减少动态效果时跳过动效。真实设备的键盘、手势阈值和通知权限仍需在目标手机上确认。

普通任务详情显示实际图片尺寸。超分详情显示原图尺寸、预期输出尺寸和真实结果尺寸，并提供超分前图片预览；生成结果出现后会自动更新，预期尺寸不会当作真实尺寸展示。

网页 / PWA 的下载面板显示原图已读取字节、总大小与进度，未知长度时显示不定进度。读取与查看原图共用鉴权缓存；有界预览和高清图块不代替完整原图。支持文件分享的手机可选择保存到相册，也可下载原图。Android 1.2 将缓存 Blob 经最多 64 KiB、逐段确认的通道写入 MediaStore Downloads，分别显示读取和写入进度；不使用 DownloadManager、不重复联网、不重新编码。取消、导航或失败清理未完成文件；启动时查找仅属于本包和指定目录/文件名前缀的 pending 项并回收。发布与取消以原子状态确定先后，已发布文件不会被回收。

「完整动效」会覆盖系统的减少动态效果，转圈和进度流光保持正常时长；「跟随系统」实时响应系统偏好，「减少动效」使用静止的状态指示，不高速循环。页面切换时底栏独立于移动的页面快照，始终保持在上方。

Android APK 使用原生沉浸模式隐藏图片查看页的状态栏和导航栏，边缘滑动可临时呼出；退出图片后恢复。二级菜单的状态栏随遮罩一起变灰，底部系统栏匹配面板底色，拖动和退场时同步更新。原生窗口分别绘制上下安全区域，兼容 Android 15 起强制的边到边显示，图标按背景亮度切换。旧 APK 必须下载安装新版并覆盖安装，单独刷新网页无法更新原生窗口控制。

网页及 PWA 在浏览器提供全屏 API 时尝试隐藏系统栏；拒绝全屏不影响查看。退出时等待退场和全屏恢复完成后再切回原来的顶部配色。iPhone Safari 的普通页面全屏能力仍受 [WebKit 平台限制](https://bugs.webkit.org/show_bug.cgi?id=206854)，网页 / PWA 无法保证隐藏系统状态栏，因此采用稳定的深色查看器配色。实际系统栏行为仍需目标设备验证。

作品页增加参考图和收藏分栏，支持分页读取较早记录。相册左右切图按帧合并触摸位移，复用相邻图片；局部重绘在减少动态效果模式下也可正常框选，完成框选后由用户自行点击输入框编辑，避免键盘自动弹出打断下一次框选。

未携带模板标签的图片统一进入「无模板」列表，已有未绑定模板的可见记录会在升级时归拢。已删除的列表保留在最近删除中；恢复后归入无模板列表。删除无模板列表后再提交新请求，会新建当前无模板列表，避免自动恢复已删除内容。

任务队列和任务详情显示四个阶段：正在传递、主模型正在思考、等待生图返回、正在回传。阶段条显示当前所处环节，不是用时百分比。CLI 的线程与回合事件决定模型启动和回传阶段；工具调用事件可用时直接采用，否则通过模型在调用前后发送的明确阶段标记更新。未收到事件时保持上一阶段，不按经过时间推算进度。阶段来源可从状态条提示查看；失败、取消和重试始终以服务端任务状态为准。

## Android 构建

客户端源码位于 `android/`，仅依赖 Android 平台 API，无第三方运行时 SDK。安装 JDK 17 或更新版本、Android SDK Platform 36、Build Tools 36.0.0 后执行：

```powershell
./android/build.ps1 -SdkRoot C:/Android/Sdk -JdkRoot C:/Java/jdk-21 -SigningDir C:/Private/ImageStudioSigning -OutputDir C:/Builds/ImageStudio
```

脚本使用 aapt2、javac、d8、zipalign 和 apksigner，在指定输出目录生成 APK 与校验文件并验证签名。必须显式指定已有签名目录和隔离输出目录的绝对路径；缺少密钥或密码会停止，不生成替代签名。签名目录包含 `image-studio.jks` 和 `store-password.txt`，仅在本地读取，请私下备份。私钥、密码、构建缓存和 APK 不进入 Git。原生能力更新需要覆盖安装同签名新版 APK。

也可以在 GitHub Actions 中从 `main` 手动运行「Android 签名构建」。`android-release` 环境应只允许 `main` 分支，配置 `ANDROID_SIGNING_KEYSTORE_B64` 和 `ANDROID_SIGNING_PASSWORD` 两个 Secret，以及公开的证书指纹变量 `ANDROID_SIGNING_CERT_SHA256`。构建核验签名证书后，将 APK 和 SHA-256 校验文件放入 `image-studio-android` 构建产物。发布需要单独上传经过验证的 APK。

从旧证书迁移到新证书时，同包名的新版需要先卸载旧 Android APK 再安装。卸载会清除本机应用数据，需要重新登录。之后继续使用同一新证书签名即可覆盖更新。

客户端固定连接 `https://image.arcol.site/`。自行部署需要同步修改 HOME、可信主机、两个通道的目标源和前端来源校验。禁止明文网络、文件 URL、混合内容与第三方 Cookie，不使用通用 JavaScriptInterface。系统栏通道仅接受查看器状态和两个颜色；独立缓存保存通道仅接受文件名、图像类型、大小与有界字节块，不能选择任意路径或发起网络请求。两个通道均向精确信任来源的主框架移交，导航后失效。上传使用文档选择器，无需整个相册或存储权限。

下载 APK 后放在服务端源码目录的 `downloads/image-studio.apk`，应用会通过 `/downloads/image-studio.apk` 提供下载。发布前核对证书指纹，常规更新沿用当前发布证书，主动更换证书时按上面的步骤迁移。Web App 清单在 `/static/manifest.webmanifest`，Service Worker 从 `/sw.js` 注册；Android WebView 同样启用该缓存。

原图、缩略图与固定的超分原图使用本机持久 Cache Storage，合并同一文件的同时请求。缓存最多 192 MB、300 项，超额时删除较早缓存；大于总预算的单文件直接联网加载。重启页面或应用后可以复用缓存，浏览器仍可能因系统存储压力清理。登录状态在工作进程首次使用缓存时验证，此后最多缓存 30 秒授权检查结果；页面 API 返回未登录或主动退出登录时会清除图片缓存。账户设置可查看占用并清空。鉴权失败响应、下载附件、API JSON、临时候选图、会话及订阅凭据不会缓存；缓存不可用时继续从网络加载。

## 验证

```bash
python -m unittest discover -s tests -v
npm ci --ignore-scripts
npm test
```

后端测试覆盖润色与尺寸快照、模板保存、删除恢复及安装资源；DOM 测试验证多次轮询与列表重排不会重新创建缩略图。APK 构建与签名验证不等同于特定手机的运行测试，安装后仍应在目标设备检查系统选择器、键盘、下载和返回手势。

系统栏集成测试：准备独立测试设备和已有的专用 QA 签名材料后执行 `./tests/android/run.ps1 -SdkRoot D:/Android/Sdk -DeviceSerial emulator-5568 -SigningDir C:/absolute/path/to/qa-signing`。脚本只读取所指定的签名，不创建或替换密钥；每次在被忽略的 `.build-cache/android-qa/` 新目录构建独立 QA 包，并在指定设备运行 Activity 与网页通道测试。不要把 QA 签名用于发行。测试使用本地页面，不登录账户、不调用生图；代理启动的模拟器须在测试结束后立即关闭并验证进程退出。
