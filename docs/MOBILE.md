# 独立移动应用

工作台同时提供 Android 安装包和 Web App，两者连接同一服务端、账户、任务和图库。生图仍由 LA 上的官方 Codex CLI 执行；手机锁屏或关闭应用不会取消已提交任务。

## 安装

- Android 10 及以上：打开工作台的「安装应用」，下载安装包，允许当前浏览器安装此应用。首次打开使用工作台用户名和密码登录；无需重新授权服务器上的 Codex 订阅。
- iPhone：用 Safari 打开工作台，在分享菜单选择「添加到主屏幕」。
- Android 浏览器：也可以在浏览器菜单选择「安装应用」或「添加到主屏幕」，使用 Web App。

Android 版本具有独立图标、窗口和会话，主要采用竖屏布局。系统图片选择器支持一次导入多张图片，下载使用系统下载管理器保存到「下载」目录。应用需要联网，不包含本地生图模型。

## 竖屏交互

底部为创作、作品、任务、模板四个入口。创作页切换生成 / 超分，参数从生成按钮旁的摘要打开。提交后保留草稿并原地反馈；参考图库、作品和上传统一放在图片选择面板。头像菜单提供设置、最近删除、安装应用和退出登录。设置整合账户与调用设置，按分区自动保存。作品只展示结果，任务按批次分组并用一条分段进度条汇总。

「帮我润色」默认关闭。开启后使用独立调用提示词，由当前模型设计构图、层次、光线、配色和风格标签，再调用生图工具。原始正文仍保存在任务中，完整调用和模型输出可在记录、日志中查看。两套调用提示词均可在调用设置中编辑。

「图像尺寸」支持自动、1K、2K、4K 长边。该值传给模型作为原生生图要求。内置工具不提供强制像素参数，因此并不保证输出严格等于所选像素；系统保留真实产物，不自动放大伪装分辨率。图片详情显示实际宽高。润色、尺寸、画幅等设置随模板保存，并随任务固定，重试使用原任务配置。

任务轮询通过 DOM 差异更新，保留未变化的图片节点，避免每次轮询重新创建缩略图。图片与图集删除后进入「最近删除」，可恢复；底层文件和历史引用继续保留，不会打断模板或任务重试。图集删除不取消进行中的任务；再次通过同一模板提交会重新显示该图集。

点图片直接打开全屏查看器，先显示已解码的缩略图，高清预览解码完成后再替换，打开和切图都不会出现空白帧。双指缩放、单指平移（松手后带惯性滑行），双击在手指位置平滑放大到 2–3 倍、再次双击回到适应画面；适应大小时可左右滑动切图、下滑关闭，更多菜单提供 100% 原生像素。单击切换操作栏会等待双击判定（约 260ms）。底栏集中图片操作，ⓘ 面板展示名称、标签、提示词与来源；速改输入框可提交一句修改要求。在查看器里输入速改或重绘要求时，键盘和输入面板浮在图片上方：图片的缩放和屏幕位置保持不变，输入法候选栏改变键盘高度也不会移动图片和选区；确认输入法候选的回车不会提交表单。局部重绘可框选最多 6 个不重叠区域，各区域单独或共用要求，并行处理后合成一张图。详见 [局部重绘](LOCAL_EDIT.md)。

列表、查看器、编辑模式和面板统一使用 history 返回栈，系统返回或关闭每次退出一层。通用面板支持拖动关闭；系统或设置减少动态效果时跳过动效。真实设备的键盘、手势阈值和通知权限仍需在目标手机上确认。

普通任务详情显示实际图片尺寸。超分详情显示原图尺寸、预期输出尺寸和真实结果尺寸，并提供超分前图片预览；生成结果出现后会自动更新，预期尺寸不会当作真实尺寸展示。

网页 / PWA 的「下载」面板显示原图实际已读取字节、文件总大小和进度，未提供长度时显示不定进度；准备完成后显示原始尺寸与文件大小。读取与查看原图共用本机鉴权缓存，命中时不重新下载；有界预览与高清图块不代替完整原图文件。支持文件分享的手机可点击「保存到相册 / 分享」，在系统菜单中保存图片；也保留「下载原图」。关闭面板取消读取，保存沿用原文件，不重新编码。Android 独立客户端仍通过系统下载管理器保存。

「完整动效」会覆盖系统的减少动态效果，转圈和进度流光保持正常时长；「跟随系统」实时响应系统偏好，「减少动效」使用静止的状态指示，不高速循环。页面切换时底栏独立于移动的页面快照，始终保持在上方。

Android APK 1.1.0 使用原生沉浸模式隐藏图片查看页的状态栏和导航栏，边缘滑动可临时呼出；退出图片后恢复。二级菜单的状态栏随遮罩一起变灰，底部系统栏匹配面板底色，拖动和退场时同步更新。原生窗口分别绘制上下安全区域，兼容 Android 15 起强制的边到边显示，图标按背景亮度切换。旧 APK 必须下载安装新版并覆盖安装，单独刷新网页无法更新原生窗口控制。

网页及 PWA 在浏览器提供全屏 API 时尝试隐藏系统栏；拒绝全屏不影响查看。退出时等待退场和全屏恢复完成后再切回原来的顶部配色。iPhone Safari 的普通页面全屏能力仍受 [WebKit 平台限制](https://bugs.webkit.org/show_bug.cgi?id=206854)，网页 / PWA 无法保证隐藏系统状态栏，因此采用稳定的深色查看器配色。实际系统栏行为仍需目标设备验证。

作品页增加参考图和收藏分栏，支持分页读取较早记录。相册左右切图按帧合并触摸位移，复用相邻图片；局部重绘在减少动态效果模式下也可正常框选，完成框选后由用户自行点击输入框编辑，避免键盘自动弹出打断下一次框选。

未携带模板标签的图片统一进入「无模板」列表，已有未绑定模板的可见记录会在升级时归拢。已删除的列表保留在最近删除中；恢复后归入无模板列表。删除无模板列表后再提交新请求，会新建当前无模板列表，避免自动恢复已删除内容。

任务队列和任务详情显示四个阶段：正在传递、主模型正在思考、等待生图返回、正在回传。阶段条显示当前所处环节，不是用时百分比。CLI 的线程与回合事件决定模型启动和回传阶段；工具调用事件可用时直接采用，否则通过模型在调用前后发送的明确阶段标记更新。未收到事件时保持上一阶段，不按经过时间推算进度。阶段来源可从状态条提示查看；失败、取消和重试始终以服务端任务状态为准。

## Android 构建

客户端源码位于 `android/`，仅依赖 Android 平台 API，无第三方运行时 SDK。安装 JDK 17 或更新版本、Android SDK Platform 36、Build Tools 36.0.0 后执行：

```powershell
./android/build.ps1 -SdkRoot C:/Android/Sdk -JdkRoot C:/Java/jdk-21
```

脚本使用官方 aapt2、javac、d8、zipalign 和 apksigner 编译，生成 `downloads/image-studio.apk` 和 SHA256 校验文件，并验证 APK 签名。首次构建生成 `android/signing/`，之后复用同一签名证书以支持覆盖安装；请私下备份整个目录。签名私钥、密码、构建缓存和 APK 均被 Git 忽略。更改客户端原生功能后，应递增 `AndroidManifest.xml` 的 versionCode 和 versionName；网页界面更新无需重新安装 APK。

当前客户端固定连接 `https://image.arcol.site/`。自行部署时修改 `MainActivity.java` 的 HOME、trusted 主机校验、消息通道的目标源，以及应用包名。生产构建禁止明文网络、文件 URL、混合内容和第三方 Cookie，不提供 JavaScript 原生权限桥。系统栏使用仅向可信主框架发送的 WebMessagePort，只接受查看器状态和两个十六进制颜色；导航时销毁旧通道，不开放文件、凭据或其他原生操作。OpenAI 授权页面交由系统浏览器打开。上传使用文档选择器，不索取整个相册或文件系统权限。

下载 APK 后放在服务端源码目录的 `downloads/image-studio.apk`，应用会通过 `/downloads/image-studio.apk` 提供下载。发布前比较新旧证书摘要，保持同一签名以支持覆盖安装。Web App 清单在 `/static/manifest.webmanifest`，Service Worker 从 `/sw.js` 注册；Android WebView 同样启用该缓存。

原图、缩略图与固定的超分原图使用本机持久 Cache Storage，合并同一文件的同时请求。缓存最多 192 MB、300 项，超额时删除较早缓存；大于总预算的单文件直接联网加载。重启页面或应用后可以复用缓存，浏览器仍可能因系统存储压力清理。登录状态在工作进程首次使用缓存时验证，此后最多缓存 30 秒授权检查结果；页面 API 返回未登录或主动退出登录时会清除图片缓存。账户设置可查看占用并清空。鉴权失败响应、下载附件、API JSON、临时候选图、会话及订阅凭据不会缓存；缓存不可用时继续从网络加载。

## 验证

```bash
python -m unittest discover -s tests -v
npm ci --ignore-scripts
npm test
```

后端测试覆盖润色与尺寸快照、模板保存、删除恢复及安装资源；DOM 测试验证多次轮询与列表重排不会重新创建缩略图。APK 构建与签名验证不等同于特定手机的运行测试，安装后仍应在目标设备检查系统选择器、键盘、下载和返回手势。

系统栏集成测试：在独立测试设备启动后执行 `./tests/android/run.ps1 -SdkRoot D:/Android/Sdk -DeviceSerial emulator-5568`。脚本构建独立 QA 包和测试签名，运行真实 Activity 与网页通道，断言状态栏 / 导航栏隐藏、焦点恢复、菜单遮罩配色、实际顶部像素及关闭恢复。测试使用本地页面，不登录账户、不调用生图。模拟器测试结束后必须立即关闭；测试包和私钥仅保留在被忽略的 `.build-cache/android-qa/` 中。
