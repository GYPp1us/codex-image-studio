# 图片直连、独立润色与显影

新任务在提交时冻结图片通道、请求模型和质量、显影帧数、允许降级与提示词格式。旧任务没有 `generation` 快照时继续使用原 CLI 流程，不补造请求或模型记录。

## 三个通道

| 通道 | 请求 | 模型回合 | 渐进图 |
| --- | --- | --- | --- |
| 图片直连（默认） | 订阅端 `codex/images/generations`；有参考图则 `codex/images/edits` JSON | 无额外派发模型 | 开启时请求 `stream` 与 `partial_images`；服务返回 JSON 时只展示最终结果 |
| Responses 直连 | 订阅端 `codex/responses`，显式配置 `image_generation` 工具 | 保留轻量派发模型 | 消费真实工具 partial 事件 |
| CLI 兼容 | 原有 `codex exec` 与内置图片工具 | 有 | 当前不提供中间图片帧 |

通道使用本项目独立 `CODEX_HOME` 的订阅凭据；没有 API Key 计费路径，也不会把凭据交给模型或写进调用记录。直连限定第一方 HTTPS 地址，禁止重定向和响应中的外部图片 URL。每次请求生成新标识；单图、参考图、响应流、像素量与执行时限受限。

图片模型、图片质量与文本模型的推理强度是不同参数。设置中的图片模型/质量是**请求值**，不代表订阅端一定执行。Responses 的轻量派发也不等于用户选择的独立润色步骤。

## “帮我润色”

开启后先进行独立文本调用：输入原始正文和参考图，只允许输出改写后的图片提示词，不配置生图工具。保存该正文及实际调用记录后，再用这份正文发出图片请求。CLI 文本降级显式禁用 `image_generation`，不会把“润色并生图”混成一次请求。润色失败不悄悄改用原文继续生图。

普通生图、速改、区域重绘和超分图块使用共用图片适配器。超分视觉验收是独立文本/视觉调用；结果仍由原有融合、配准、尺寸验收及检查点决定，不因一次 HTTP 200 就宣告任务成功。

## 降级、重试与取消

允许降级时，只有确定未启动图片生成的错误（例如连接建立前失败、明确不支持通道或参数）才切换 CLI。降级记录保留原请求值、来源与原因；CLI 没有回显的图片模型和质量继续显示未知。

额度、策略拒绝不会通过切换通道重试。已发送后的读超时、连接中断、损坏或缺失的最终图片可能意味着服务已生成，系统不会自动重发。只有明确安全、可重试的临时错误才使用自动重试预算；不确定结果交给用户核对后手动决定。

取消会关闭直连请求、终止本任务 CLI、释放并发名额，并阻止迟到结果发布。显影编码线程只产出内存数据；事件循环确认任务仍有效后才替换已发布预览，取消后的线程不能覆盖最后一帧。

## 真实显影与进度

每个 partial 都经过完整图片校验，然后生成至多 1024px 的独立预览。原始最终图片按原字节保存，预览不替代原图。任务详情通过登录保护的 SSE 接收轻量更新，再读取受保护的最新预览；离开详情或页面隐藏时断开订阅。

显影只来自真实图片事件，不用计时器、模糊最终图或伪造百分比模拟。服务没有提供帧时，如实等待最终结果。失败或取消保留的显影帧标为“非最终作品”；切换调用时清除另一调用的图片，旧失败调用不会借用重试后的成品。

普通任务按实际路径显示独立润色（若开启）、发送、派发（若需要）、生图、接收、保存。超分图块直接通道显示三行调用阶段，Responses/CLI 保留派发行；各级检查点与合成阶段继续独立显示。

## 详情与数据接口

调用记录分别保存 `requested`、`provider_reported`、`actual_image`，以及有限的 usage、作用域和降级信息。服务未回显模型/质量就显示“未回显”；服务声称的模型名称也不能证明其内部路由。实际尺寸和格式从完整校验的图片读取。请求 `auto` 而回显 `low` 属于合法自动选择；明确请求 `max` 却回显 `low` 会标示差异。

- `GET /api/jobs/{id}/generation-calls`：分页调用历史；包括独立润色、图块图片、视觉验收及降级。
- `GET /api/jobs/{id}/generation-events`：任务当前调用的 SSE 摘要，不携带图片 base64 或凭据。
- `GET /api/jobs/{id}/generation-preview/{call_id}`：本任务真实显影预览，缓存清理后可返回 404。

详情默认显示最新调用，可切换历史记录；图片信息页展示最近调用的参数对照。列表只携带轻量摘要，完整模板保留在任务详情和提示词快照中。

## 验证边界

公共 Images API 文档不是 ChatGPT 订阅端的协议保证。此前六次订阅探测仅提供有限观察：两次补测的图片头尺寸未匹配请求，`max` 请求回显 `low`，未发现顶层图片模型字段。没有保留原始响应、图片与 partial 内容，不能据此宣称所有请求忽略参数、确认底层模型，或完成编辑保真/显影画面验收。

本次实现的自动协议测试使用合成图片及模拟流，覆盖实时 partial、最终完整性、取消和失败分支；测试不会默认消耗订阅额度。另外完成了三次独立的真实订阅合成请求：润色成功，图片直连只返回最终图，Responses 返回两张不同的真实 partial 及最终图，四张图片均完整解码并保留哈希。尺寸仍与请求不同，图片模型未回显；这些观察不保证其他账号、模型或请求的行为。见 [实测记录](DIRECT_BACKEND_LIVE_QA.md)。
