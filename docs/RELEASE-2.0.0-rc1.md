# Image Studio v2.0.0-rc1

## 要求与验收

| 场景 | 验收条件 |
| --- | --- |
| 作品归档 | 每张作品有一个主位置。升级后保留自定义名称、旧入口、已删除项目和历史生成来源。重启后空目录和手动整理结果仍在。 |
| 嵌套模板 | 根目录、普通目录和模板内均可建组。给原目录保存正文或纯参考图配方即可成为模板。嵌套表示目录关系，使用父级配方须显式选择。按来源查找可定位到当前目录。 |
| 整理与撤销 | 在模板 A 将 a1–a30 一次建组，b、c 留在本层。普通移动遵守当前模板边界。明确移出模板才将整棵子树移至该模板的上一级。事务、操作编号和带冲突检查的撤销应能处理断流和并发。 |
| 手势 | 长按 420 ms、起步容差 10 CSS px。按阅读顺序连续增减选，回拖收缩，在 48 px 边缘区跨屏滚动。取消或第二指恢复本笔前的选择。松手保持多选，点击、Shift、Ctrl/⌘ 均可使用。 |
| 导航 | 可点祖先路径、展开目录树或浏览移动目标。确认才执行写入，返回依次关闭面板、多选和目录。恢复每层滚动锚点；图标有可读名称，触摸热区至少 44 px。 |
| 弱网首页 | 创作页启动不拉完整目录。子目录与图片分别分页，首屏优先、图片占位、转场期间合并绘制。以 200 个目录、5,000 张作品、200 ms RTT、1.6 Mbps、4 倍 CPU 限速记录反馈和帧间隔，P95 目标分别为 100 ms 和 20 ms。 |
| 连接恢复 | 前台 4 秒无业务回包后独立探测本站，3 秒含正文超时。首个失败显示可点重连，按 1、2、4、5 秒重试；恢复目标为 10 秒内更新任务。后台停探测，返回后立刻检查。保留目录、草稿、选区和查看器。 |
| 状态隔离 | 仅图库慢时任务仍能刷新。代理与直连双向切换、无系统网络事件、只回响应头及迟到响应均要覆盖。重连合并重复点击，只核对写入结果，生成只产生一份。 |
| 回归与发布 | 保留 11 月 19 日查看器黑底、缩略图占位和退出定位。验证桌面键鼠、移动浏览器及 Android WebView。以候选标签和 GitHub 预发布提供该版本。 |

## 验收记录

测试图库含 200 个目录和 5,000 张作品，生成与整理使用独立的测试数据库。以下数值来自 Windows 上实际运行的 Chrome，弱网场景使用 200 ms RTT、1.6 Mbps 下行和 4 倍 CPU 限速。

| 项目 | 实测 |
| --- | --- |
| 首页 | 已登录冷启动 1,598 ms，Service Worker 缓存后的启动 371 ms。两次进入创作页均未请求作品目录。 |
| 目录动画 | 12 次进出目录，转场窗口内采集 355 帧。交互至下一帧 P95 为 7.0 ms，帧间隔 P95 为 8.2 ms。 |
| 触摸整理 | 一次长按拖过三屏选中 65 张，回拖缩小范围，取消恢复本笔开始前的选区，抬手即停止自动滚动。 |
| 连接恢复 | 保持系统在线，挂起请求，再切向本地转发代理或直连。两次于 6.96 秒显示重连入口，分别在通路恢复后 742、744 ms 收到新的任务状态，30 张选区保持。单独让图库失败时任务继续更新。 |
| 数据一致性 | 对同一组 30 张作品并发提交两次，只生成一个目录。在 Chrome 与 WebKit 中丢弃写入回包，再挂起目录读取，重新确认后均可从回执直接看见并打开原分组。清空已删除目录后，提前移到别处的作品与原始任务仍可访问。 |
| Android 15 模拟器 | 独立 Chrome 与内嵌 WebView 均从长按开始选中 30 张，建组后打开作品。两端都显示深色查看器与缩略图占位，退出后保留所属目录。 |

Chrome 和 WebKit 的浏览器用例见 `tests/library-browser.cjs`。参数 `--quality` 复测拖选、动画和断线，`--startup` 复测冷启动和缓存启动。上述代理测试在回环地址上制造断流，个人设备的 TUN 切换仍需实际使用验证。
