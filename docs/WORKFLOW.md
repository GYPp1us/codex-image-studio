# 工作流说明

## 一次生成

1. 输入提示词，上传参考图或从图库选择，并设置数量、画幅、模型和思考强度。
2. 提交时保存原始提示词、参考图 ID、选项及调用模板快照。
3. 携带模板标签时，按模板 ID 归入对应产物列表，最终正文可以不同。没有模板标签时，所有提交统一进入无模板列表，每次生成仍使用独立 CLI 会话。
4. 队列按并发上限执行，每次尝试都启动新的 `codex exec --ephemeral` 会话。
5. 参考图复制到任务独立目录，通过 CLI 图片参数传入，不续接上一张的聊天记录。
6. 内置工具生成图片，后端按本次 `thread_id` 找到真实文件，校验后存入图片库。
7. 更新卡片集；任务临时参考图副本清理，图库原件保留。

列表名称是显示标签。重命名不改变模板身份，不影响后续自动归组；提示词文本本身不作为模板身份的判断依据。

## 模板

保存时打开编辑弹窗，可以改名称、裁剪正文和移除参考图。只保留需要复用的部分即可，甚至可以创建只有参考图的模板。弹窗修改不影响创作区当前完整请求。

模板拥有独立 ID，相同正文也可以保存成不同模板。载入时恢复正文、参考图及顺序、画幅、透明背景、模型和思考强度，并在“归入”行显示模板关联。后续增删正文或参考图不自动解除关联，可以在“归入”行解除关联后提交到无模板列表；正文差异较大时只提醒，不自动阻止提交。

编辑已保存模板保留其 ID，之后的请求仍进入同一列表。已提交任务继续使用自己的正文、图片、模型和调用模板快照。

图片卡片和图集支持移入「最近删除」，可从头像菜单恢复。底层文件和历史引用保留，模板载入与重试继续可用。从模板编辑框移除参考图只改变关联，不删除图库原图。新任务使用同一模板时会重新显示已移除的对应图集。

## 调用提示词

头像菜单 → 设置 → 调用提示词，可编辑驱动 Codex 的外层模板。创意提示词与调用模板分别保存。

普通生成和「帮我润色」使用两套独立模板。普通模式保持原创意正文；润色模式要求当前执行模型主动设计构图、光线、配色和风格标签后再生图。原始正文不被改写，任务保存选中的调用模板和模式快照。润色模式不需要额外 API 服务。

| 变量 | 内容 |
| --- | --- |
| `{prompt}` | 原始创意提示词，必填 |
| `{ratio}` | 请求画幅 |
| `{size}` | 原生尺寸要求，自动或 1K / 2K / 4K 长边 |
| `{transparent}` | 是否请求透明背景 |
| `{references}` | 本次参考图名称，没有时为 `none` |

只替换固定变量，不执行 Python 格式化表达式。先替换模板变量、最后插入创意正文，正文里的花括号不会再次展开。

编辑后只影响新提交任务；排队任务和自动重试使用原快照。生成记录可查看实际展开的调用提示词。

为兼容已有调用模板，未写 `{size}` 时会在调用前补充尺寸要求。实际宽高以工具产物为准。移动应用、离线与安全设计见 [移动应用说明](MOBILE.md)。

调用要求还包含「GPT-Image-2.5 Sunburst（gpt-image-2.5-sunburst），思考强度 max」，并要求执行模型把这项要求带入生图工具的提示词。普通、润色和已保存的自定义调用模板均适用，每个新任务固定该要求。此处是订阅 CLI 链路中的提示词请求，不代表底层路由已经选定或验证。公开 Images API 提供独立 `model` 和 `quality` 参数，其中 `max` 是画质档位，和外层 CLI 的思考强度不同；本项目不切换付费 API。[官方生图文档](https://developers.openai.com/api/docs/guides/image-generation)

## 交互与批次

生成后保留草稿和当前页面，原地显示批次状态与结果入口。每批任务按 `batch_id` 归组，批次分页不会截断其中的任务。作品只展示图片结果，处理中与失败任务通过状态条跳转任务页；任务页展开批次后提供取消、重试、日志和来源设置。

速改以当前图片为参考，请求其原生画幅与尺寸，按速改设置保存模型、强度、润色和模板关联。新作品记录来源，重命名不会丢失速改标记。完整实现说明见 [交互重构](UI_IMPLEMENTATION.md)。

## 队列

```mermaid
stateDiagram-v2
    [*] --> queued
    queued --> running: 有空闲槽位
    running --> succeeded: 收集到真实图片
    running --> retrying: 临时错误
    retrying --> running: 退避后重试
    running --> failed: 永久错误或达到上限
    queued --> cancelled: 取消
    running --> cancelled: 取消并停止进程
    retrying --> cancelled: 取消
    failed --> queued: 手动重试
    cancelled --> queued: 手动重试
```

鉴权、额度、工具能力或策略错误停止自动重试；网络等临时错误递增等待后重试。单次超过 15 分钟会终止后台进程。

重启后尚未开始的任务保留，正在执行的任务标记失败，等待用户决定是否重试，避免意外重复消耗额度。

## 图片收集

可选的超规格图像拼接会在原图之后继续多块 AI 补绘与确定性配准融合，也可从已有产物直接发起。细节见 [拼接工作流](STITCHING.md)。

某些服务器沙箱会拒绝 shell 的网络命名空间操作，导致“已生图、复制失败”。工作台直接从当前会话的生成目录收集，不要求 shell 复制，也不使用全局最新文件猜测归属。

不存在真实文件就不会报告成功。假 CLI 只用于测试应用逻辑，不会在生产生成失败时替代图片输出。
