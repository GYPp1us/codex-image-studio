## 一、执行与可观测契约（P1）

- [x] 识别现有问题：区域回调缺少机器阶段；超分切换阶段覆盖 children；失败块未持久标记；选块修复污染全局约束；缓存/调用版本不清。
- [ ] 建立共享任务进度投影：等待、发送、思考、生成、回传、配准、融合、验收；保留来源、时间和终态，不按用时伪造百分比。
- [ ] 区域任务并发进度包含零基区域 ID、机器阶段、成功输出检查点与失败原因；合成独立显示。
- [ ] 超分每级保留图块四阶段、实际检查点、配准/融合/验收状态，切换 phase 或失败后不丢已完成数据。
- [ ] 完成态具有明确终态，前端可停止绘制进度；失败只标实际失败段，成功块/成功级继续表示可复用。
- [ ] 独立指令编译器，不再借用普通生图外层模板隐式拼接超分调用。
- [ ] 区分：可选历史背景、任务统一要求、图块执行模板、局部修复模板与本次修复要求、验收模板、调用/产物协议。
- [ ] 所有超分模型提示模板进入设置；模板值、启用策略和版本在提交时冻结。
- [ ] `append_system` 与 `include_source_context` 在创建入口明确选择；关闭系统模板不偷偷重新加入其创作约束，必要的调用协议/尺寸元数据单独说明并预览。
- [ ] 实际 CLI 输入按调用保存，可查看最终渲染内容、变量、模板来源、版本和作用域；不冒充无法验证的工具内部提示词。
- [ ] 选块修复只保存到 level/tile/repair_id 作用域，不修改任务统一要求，不传到无关块/后续级。
- [ ] 普通重试沿用快照；采用新全局要求/系统模板时明确新版本或另起任务，不默默混用旧块与新验收标准。
- [ ] 检查点和修复记录保留各自输入/配置来源；缓存复用由实际身份决定，不只看文件存在。
- [ ] 旧任务缺少版本/实际记录时清楚降级，不补造历史记录。
- [ ] Terra 数据代理独立验收：真实 on_progress 回调、多区域并发与终态、阶段切换、失败检查点、局部作用域、重试版本和真实调用内容。

## 二、反馈与视觉语义（P2）

- [ ] 建立动作级 pending 控制器：点击立即反馈，短时转圈、`aria-busy`、稳定按钮宽度、防重复、完成/失败恢复；不用虚假的完成乐观状态。
- [ ] 暂停/恢复调度、速改发送以及所有可能等待网络/磁盘/解码的同类操作接入；失败保留文字、选择和上下文。
- [ ] 快速返回的动作不闪烁，超过短阈值才显示连续忙碌；减少动效仍清楚显示正在处理。
- [ ] 所有选中、打开、开关、分段选项、批量选中和进度使用主题语义色；中性按压轮廓与主题激活态区分。
- [ ] 图片缓存条采用主题色；服务器总容量/工作台存储预算/已用与可用空间构成有标尺的三层展示，不将整个磁盘误标为数据库文件。
- [ ] 数据字段明确服务器容量、其他占用/实际可用、工作台已用、配置上限/剩余额度，以及 SQLite 文件大小。
- [ ] 速改毛玻璃叠加随主题推导的深色层，纯白和高纹理图片上仍可读。
- [ ] 当前预览仍在请求/解码时左上角显示加载标记，保留已有缩略图；成功消失，失败显示可重试状态，不永远转圈。

## 三、素材直接操作（P3）

- [ ] 参考图取消专用拖动按钮，直接按图片；按下即中性黑色/暗色可见轮廓，短按松开进入预览。
- [ ] 持续约 420 ms 且未越过 8 px 阈值，切主题轮廓、约 1.04 倍放大、投影和层级上浮，进入拖动并轻触反馈（支持时）。
- [ ] 激活前不抢原生横向滚动；激活后 y 轴固定，横向位移 rAF 跟手，不允许跨行/拖到其他区域。
- [ ] 相邻项让位、边缘自动横滚、落位动画完整；取消、指针丢失、切页、旋转、卸载时回滚并清理浮层。
- [ ] 长按结束不误触图片预览/移除；保留键盘排序和清晰的无障碍说明，无需可见手柄。
- [ ] 作品长按进入批量选择，当前图被选中；操作条呈现数量、当前范围全选/清除、收藏、删除及适用的批量动作。
- [ ] 批量选择时点击改为选择，关闭/返回退出一层；分页和轮询不重置选择，失败逐项反馈，删除仍可恢复。
- [ ] 不让参考图排序、作品批量长按、查看器手势和系统返回互相争夺。

## 四、原图缓存保存（P4）

- [ ] 网页和 Android 统一从 `StudioImages.original` 获得相同已鉴权原图 Blob，命中缓存不二次下载或重编码。
- [ ] 删除 Android 绕开缓存而交给 DownloadManager 的分支。
- [ ] 设计精确同源、导航失效、请求 ID 与有界分块/背压的原生保存协议；网页不可选择任意本地路径或操作其他文件。
- [ ] Android 10+ 使用 MediaStore Downloads，写入中保持 pending，完成后公开；取消/失败删除本次未完成项，保留其他文件。
- [ ] 下载面板分别展示读取缓存/原图与写入保存的真实进度、文件名、尺寸和完成结果。
- [ ] 新 APK 使用同一签名，原生接口与网页能力探测兼容；旧 APK 给出清楚的升级路径，不悄悄回退到系统下载器。
- [ ] Terra 原生代理独立构建、证书/包身份/哈希核对和缓存保存验收，测试后回收模拟器。

## 五、任务工作区（P5）

- [ ] 已完成的普通、重绘和超分任务不再显示执行进度条，只保留完成/数量/产物等结果信息。
- [ ] 超分收起时使用短横线分段进度，展开后才出现复合进度板。
- [ ] 复合进度以一组横向、不换行的图块列呈现；每块的发送/思考/生成/回传纵向小格组成一列，准备/配准/融合/验收等总步骤纵向合并为整列。
- [ ] 每级一块进度板，级别与检查点明确；横向可滚动，左右淡出只在实际仍可滚动的方向出现。
- [ ] 更新单元格不重建整板、不丢滚动；可跟随当前活动列，手动浏览时停止抢回位置。
- [ ] 失败处理复用同一渲染器，实际失败段红色，成功检查点保持完成色，不把整级所有块都改红。
- [ ] 详情内含日志/调用记录，不再额外压入日志子页面。
- [ ] 超分尺寸、预算、切法与失败诊断合为一个“超分检查”工作区；成功/进行中的任务也能看，不要求先失败。
- [ ] 保留返回语义、选块、比较输入输出、修复草稿与滚动位置，避免详情/日志/预算/失败不断套层。

## 六、提示词工作区（P6）

- [ ] 设置中的超分系统提示采用分类列表与编辑区，显示范围、变量、恢复默认、版本差异和实际效果预览。
- [ ] 专用超分页、图片快捷超分、生成后超分入口都有清楚的系统提示拼接选项，并展示继承来源。
- [ ] 紧凑横向摘要组合“系统提示 拼接/不拼接”“历史背景 可选”“查看最终指令”，主要任务文字保留足够宽度。
- [ ] 默认值只用于新的草稿；保留旧草稿时标明来源并提供恢复默认，避免不同入口无解释地不一致。
- [ ] 任务统一要求只读快照，与失败页的“本次选块修复”明确分开；修改全局配置不会暗中修改既有任务。
- [ ] 展示被关闭/沿用/覆盖的组件和生效范围；无真实记录时不生成假的历史“实际发送”。

## 七、横屏编排（P7，其他模块完成后实施）

- [ ] 先冻结已验收的竖屏行为；按可用宽高而非设备名选择布局，不把 390px 单列简单拉宽。
- [ ] 紧凑横屏采用窄导航轨道；创作左侧提示词/参考图，右侧参数/结果/主要动作，减少重复标题与无用空白。
- [ ] 超分采用原图/切法画布与任务要求/分级进度/预算双栏；提示拼接摘要横向排布。
- [ ] 作品采用图库与选择/检查器联动，查看器以大画布配侧栏操作；空间不足时只保留主从两栏，避免三栏均不可用。
- [ ] 任务采用左任务列表、右详情/检查器，日志、预算、失败检查作为同一个工作区内的视图，不重复叠屏。
- [ ] 模板采用左列表右编辑；设置采用左分区右表单；重绘与失败处理尽量同时呈现画布、要求和提交。
- [ ] 键盘、刘海/手势区、左右手操作区域纳入布局；主按钮始终可达，画布有效面积优先。
- [ ] 旋转保留草稿、当前图片、选择和检查位置；进行中的拖动取消回滚；查看器围绕当前图像锚点重布局。
- [ ] Android 解除固定竖屏，尊重用户系统旋转策略；原生 insets/系统栏与网页一起验收。
- [ ] 横竖布局切换、面板联动、返回和共享元素动画规格不少于竖屏；减少动效提供等价静态反馈。
