# 加载与恢复

本轮修复客户端在弱网、图片读取停滞和后台恢复时占用旧请求的问题。未调整模型调用、调度器、数据库或图片生成结果。

## 启动与页面生命周期

- 认证后并行获取基本状态、设置和辅助资料。基本状态与设置完成即可显示工作台；账户、连接检查、模型目录、首批图片和任务资料稍后补齐，不再共同挡住首屏。
- 首批图片从 200 张降至 80 张，任务中的超分详情独立、最多 6 路补齐，不阻塞主列表同步。
- 本地草稿先恢复正文、参数和引用 ID，再补参考图与模板资料。仅明确返回 404 时移除失效引用；临时网络错误不会删除参考图。资料加载期间的用户编辑不会被旧响应覆盖。
- 页面隐藏时保存已恢复的草稿，停止轮询，取消后台同步读取、预览解码和高清图块读取。用户主动操作的读取由调用方管理，不因普通前台恢复事件被静默取消。认证完成但草稿尚未恢复的启动阶段不会覆盖已保存草稿。
- `visibilitychange`、从 BFCache 返回的 `pageshow.persisted` 和 `online` 触发恢复；首次加载的 `pageshow` 不重启启动。失效的同步锁不再阻塞新请求，重新拉取数据、继续预览和图块加载，并结束后台遗留的有限时长过渡。打开的面板和图片缩放位置保留。
- 辅助资料仅在成功后标记为已加载，失败或中止后由后续同步补读。草稿先渲染占位，等首批图片读取和主同步首次完成后仅补查仍缺失的引用，避免冷启动为已有引用额外请求。补查失败仍保留引用并重试。
- 写入后的刷新会等待正在进行的旧同步，再发起一次新同步，不用写入前已经开始读取的旧结果确认提交。
- 会话与同步版本限制旧响应的作用范围，退出或切换账户后不能回写旧账户数据。恢复不会重放生成、保存、删除等写入操作。

## 网络与图片

| 操作 | 释放条件 | 用户体验 |
| --- | --- | --- |
| 普通只读接口 | 15 秒，包含 JSON 响应体 | 停止等待，可重试；恢复前台会重新同步 |
| 订阅状态与存储统计 | 默认 30 秒，调用方可覆盖时限 | 容纳服务端较慢的状态命令与目录统计 |
| JSON 写入 | 45 秒，包含 JSON 响应体 | 提示提交状态待确认，不自动重发 |
| 浏览器 FormData 上传 | 连续 45 秒无上传/响应字节进展；收到响应头时重新计时 | 持续上传不受总时长限制；超时提示先核对列表 |
| Service Worker 图片鉴权 | 8 秒，包含响应体 | 无法确认账户时使用网络，不读取私有缓存 |
| 图片网络读取 | 响应头 15 秒、响应体连续 20 秒无进展 | 终止停滞读取，释放通道 |
| 原图下载 | 响应头或连续读取 20 秒无进展 | 保留真实字节进度，允许重新读取；连续传输不限总时长 |
| 查看器有界预览 | 加载与解码合计 20 秒 | 保留已有缩略图，显示重试入口 |
| 高清图块 | 加载 15 秒、解码 10 秒 | 释放并发槽，有限次数退避重试；旧解码不能覆盖新尝试 |
| 缓存写入 | 等待真实 Cache API 写入完成或失败；网络源受无进展超时保护 | 后台执行，串行维护，清缓存会等待真实写入，不用锁流取消提前放行 |
| 文档/静态资源网络读取 | 45 秒等待响应头，真实网络错误立即回落 | 给弱网首字节留出时间；失败尝试通用离线缓存，否则返回可重试错误，不自动跳转覆盖用户操作 |

FormData 在支持 `XMLHttpRequest` 的浏览器中按真实字节进展延长等待；无此接口的运行环境降级为有总时限的 Fetch。写入请求超时只能说明客户端停止等待，不能证明服务器未提交，因此客户端不自动重发。

Service Worker 仍先确认认证和账户缓存分区。同一 URL 的并行消费者可共享正在建立的请求；取消其中一处不取消其余消费者，全部取消才中断上游。退出登录会失效分区、终止活跃传输并清理私有缓存。通用离线页不包含账户页面快照。

注销/主动清缓存的撤销世代与身份切换的分区维护版本分别追踪。正常身份更替可使用新分区加载；注销前仍在等待鉴权或缓存的旧请求不能在注销后新建网络读取。

## 按钮反馈

共用 `StudioFeedback`，同一操作在 UI 重绘后继续显示忙碌并防止重复提交：

- 纯文字按钮：原内容保留布局占位并隐藏，转圈位于按钮中心。
- 有图标的按钮：只隐藏当前可见图标，转圈与其中心重合，文字不变。隐藏的成功态图标不参与定位。
- 完成、失败或取消后恢复原内容、可访问名称和禁用状态。旧操作结束不能清除同一节点上新操作的反馈。
- 系统分享使用同步启动模式，保留用户点击的临时授权；不为显示转圈而推迟 `navigator.share()`。
- 减少动效时保留静态加载标记，不使用极短动画模拟停用。

覆盖生成、暂停调度、速改、头像保存/恢复默认、参考图分页/上传、任务重试、显影帧重试与分享等入口。
