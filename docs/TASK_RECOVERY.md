# 任务详情与超分恢复

任务列表每个任务只保留一个“详情”入口。详情中的概览、图像调用和日志导航只滚动当前页面；旧超分详情入口也复用同一页面。失败的超分任务在“失败处理”窗口查看检查点、尺寸、切法、预算及选块修复。诊断渲染失败或尚无切图时，恢复控件仍可访问。

## 两种继续方式

| 操作 | 行为 |
| --- | --- |
| 从当前检查点重试 | 复用完成图块，继续未完成步骤并重新审核。没有可复用缓存时明确显示“重新执行”。 |
| 忽略本级审核并继续 | 仅放行当前级、当前候选图对应的一次视觉审核拒绝；保留审核及放行记录。后续级继续独立审核。 |

放行前仍核对图块的完整无重叠覆盖、原生返回尺寸、配准和候选完整性。检查点缺失、已变化或不满足这些条件时，按钮禁用并说明原因。重绘、普通重试和取消后重新执行不会继承旧的待执行放行。

`GET /api/upscale/jobs/{id}` 的 `recovery` 字段提供两个操作的可用性、检查点状态、标签和原因。`POST /api/upscale/jobs/{id}/recover` 接受 `{"action":"retry"}` 或 `{"action":"accept_review"}`；与其他私有接口一样需要登录及 CSRF。陈旧状态返回冲突，前端读取新状态后更新按钮。操作锁按任务区分，一个任务仍在刷新时不会禁用另一个任务；连点不会重复提交。

恢复的数据库更新与磁盘检查点通过恢复日志对账；写入、提交失败或进程中断后按已提交状态恢复。放行绑定候选图与审核的哈希，不以改写原审核为“通过”来掩盖失败。

## 界面与验证

图像调用的选择器、参数表和显影区使用主题样式；未知回显保持未知，长模型名换行。显式隐藏样式避免按钮的通用布局覆盖 `hidden`。移动端选择器使用 16px 文字避免 iOS 聚焦自动放大。长错误显示三行摘要，可展开完整内容。

完整后端回归 205/205、前端回归 193/193。API35 WebView 使用隔离数据库、合成图片和生产 CSP，检验实际 CSS 解析与计算样式、长字段、隐藏控件、转义、统一入口、加载和返回、诊断失败、无检查点、冲突以及跨任务两次真实恢复 POST；队列暂停且模型为模拟实现，没有重试生产任务或消耗模型额度。Android 原生产品代码未改变，现有 1.2.0 APK 可继续使用。此处不代表完成 iOS 真机验收。
