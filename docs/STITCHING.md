# 渐进超分

超分有独立工作区，可从作品、参考图库或上传文件选择原图。4×、16×、64×均为面积倍率，对应宽高各2、4、8倍，共1、2、3级。倍率与初始块数无关。

## 每级流程

1. 将上一级通过验收的完整结果作为输入；第一层使用原图。
2. 在原图坐标规划带20%总重叠的裁图。小图允许整图处理，完整裁图长短边比不超过2。优先减少调用，再让旧接缝进入新图块中央，最后考虑接近横向4:3。初始基础网格短方向不超过2；大图会继续细分两轴，满足单块生成像素预算。
3. 每块目标宽高乘2。原生生成预算暂按1536×1024、宽高各留10%余量，单块目标最多1,274,019像素，含重叠输入最多318,504像素。仅将当前裁图与1600px完整参考图发给独立补绘会话。
4. 先测量真实返回。画幅偏差超过8%时重试；任一轴不足目标95%时保留其它块，仅把该块核心细分为4块；最多递归细分2次。满足要求的返回进入配准。生成接口尺寸与计划、接受判断及融合相互独立。
5. SIFT + RANSAC估计唯一全局二维仿射，不使用光流或局部形变。可靠匹配不足时只重试问题块，不发布假成功。
6. 以原图为几何和低频色调参考，Graph Cut找缝，7层MultiBandBlender分块融合。结果写入磁盘映射，再用libvips流式输出；画布不会一次性解码进内存。允许有界补绘边界延拓，核心区域不得缺失，透明轮廓保留。
7. 保存结果全图缩略图与原生细节检查图，执行视觉验收。未通过就保留检查点和错误；通过后才把完整结果交给下一级重新切图。
8. 最后一级通过后保存完整分辨率新作品，原图保留。

重切只提供将旧接缝纳入新块内部的机会，不保证模型一定修复。纹理不足、明显内容变化或无法配准会明确失败。

## 预算、进度与恢复

工作区展示每级切法缩略图、新旧接缝、输入与预期尺寸、本级生图及验收预算、实际调用次数、原生返回统计、本级实际结果，以及总预算和最终实际大小。初始预算每块1次生图、每级1次验收；最大调用预算包含本轮子块尝试。异常返回细分后预算会调整，并保留最初预算。新创作还有1次原图生成，原图生成后才能规划各级预算。

所有生图与验收共用全局CLI并发池，父任务不额外占名额。暂停阻止新会话，取消结束当前任务的全部子会话。进度表示完成工作量，不预测剩余时间。重试复用按输入哈希分隔的逐级检查点与已接受的相邻块。清理缓存后重试会重新生成，累计调用统计保留。

运维局部修复请求位于当前级的`diagnostics/local-repairs.json`，复用矩形编辑与已接受仿射；外部不提供可执行路径入口。

## 大图与存储

不设置单张图片字节、像素或边长上限。流式导入、缩略图和按可见区域加载的512px WebP金字塔支持超过旧6400万像素、32700px单边限制的图片。完整结果通过下载获取；图库、任务和各级预览使用有界缩略图。规划超过10万块的任务需要拆分，实际执行还受可用磁盘和总存储限额约束。

设置页的“存储上限”统计SQLite、原图与作品、缩略图、大图预览、任务缓存及工具产物；0表示不限。写入前检查配额与可用磁盘，外部生成工具的临时写入不是文件系统硬配额。超限明确失败，不自动删除用户数据。可永久清空回收站，或清理一个已停止超分任务的缓存；后者保留原图、最终作品、任务与日志，等待和运行任务不可清理。

安装需锁定的OpenCV、NumPy和`pyvips-binary`。仓库的合成图和模拟CLI测试覆盖规划、异常返回、融合、取消恢复、缓存清理和大图显示，不代表真实模型能完美保留结构。


## 失败处理与选块重绘

失败或取消的任务可打开独立“失败处理 · 选块重绘”窗口；竖屏时窗口全屏。窗口提供原图、按目标直接拼接、仿射诊断三栏，以及顶部缺边与中心接缝放大图。红色条纹标记未覆盖像素，橙框标记低可信匹配。诊断优先复用当前检查点的矩阵，低可信估计只供观察，不发布为成功作品。

点击图块或列表选择需要重绘的块，也可选择所有问题块。重绘前保留旧返回的历史副本，只失效选中块的派生检查点，未选中的返回继续复用；如果未选中的块仍有问题，任务会停下提示选择该块，不会偷偷重绘它。当前级改变后，后续级会失效并基于新结果重新执行。预算保留实际已用调用，并加入此次重绘和后续重算所需预算。

头像菜单 → 调用设置中的“超分 · 分块重绘提示词”支持`{prompt}`、`{target_size}`、`{tile_index}`、`{tile_count}`、`{bounds}`、`{injection}`。新任务保存配置快照；选块重绘可勾选使用设置中的最新提示词。配准失败的原因会加入重绘反馈。

每个超分任务都有“统一细节与画风约束”字段，注入每一级每一块，并作为验收数据。可在创建时填写、任务停止后保存，或在失败处理窗口修改后随选块重绘一起提交。不写`{injection}`占位符时，程序自动在分块要求末尾追加此约束；占位符按单次替换处理，用户内容中的花括号保持原样。


## 图块输入输出对比

失败处理窗口的每个图块行右侧都有“对比”按钮。点击后在同一画框中叠放该块完整输入（包含重叠）与模型原始返回，用“切换到输入／切换到输出”按钮切换；两张预览均先加载，切换不重新请求图片或改变画框。显示输入、要求输出和实际输出尺寸，保持各自画幅，不做配准或强行拉伸。

返回诊断会恢复原来的滚动位置，保留选中的重绘块和未提交的任务约束。竖屏沿用全屏弹窗；缺少输出时可查看输入，切换按钮不可用。比较使用登录保护的有界预览缓存，不修改原始检查点，也不发起生图调用。
