# 超规格图像拼接

创作参数中的「超规格图像拼接」默认关闭，可选择 4×、9×、16×。倍率指像素面积：分别为 2×2、3×3、4×4 网格，输出宽高各乘 2、3、4。例如 1254×1254 原图使用 16× 后为 5016×5016。

也可以在作品图片卡片或图片详情中选择「发送到超分」，直接复用该图片作为原图，选择倍率与执行模型后加入任务队列。提示词来自来源生成记录；没有生成记录的导入图片使用保留原图内容的增强要求。

## 固定流程

1. 准备原图。新创作先生成一张原图；发送已有作品时直接读取该图。
2. 按平方网格裁切。相邻块在原图坐标横向重叠 64px、纵向重叠 36px；在内部边界两侧分别扩展 32px 和 18px。输出坐标按网格边长放大。
3. 每块在独立 Codex 会话中同时附上局部裁图与完整原图。主模型必须细化该局部的补绘提示词，严格保留边界、元素位置、光照、景深、文字与内容，只增强已有细节。
4. 使用 SIFT 特征匹配与 RANSAC 估计每块唯一的全局二维仿射变换。保存矩阵、匹配数、内点比例及原图坐标中的均方根误差。禁止光流、局部非线性形变和透视变形。匹配不足时重试该块，无法可靠配准就停止，不用原图插值假充 AI 补绘。
5. 转到 Lab 空间，以原图为基准修正缓慢变化的亮度、颜色偏差。只修改低频差异，细节来自补绘图。原图仅参与几何及色调参考。
6. 使用 Graph Cut 的颜色与梯度代价在重叠区搜索接缝。为控制内存，在缩小的工作图上搜索接缝，再映射回输出坐标。
7. 使用固定 7 层 MultiBandBlender 拉普拉斯金字塔融合。大画布分块处理，采用超过金字塔支持范围的上下文边缘，拼好后只写每个块的中心有效区域，避免块处理引入新接缝。
8. 检查融合覆盖，不允许空白像素。生成原生像素的主体、前景、背景和接缝局部检查图，并附完整原图与结果全图，让主模型进行视觉检查。只有结构检查和视觉检查都通过才将最终图存入产物列表。

仿射重采样内部最多使用 2 个输出像素的补绘边界延拓；画布最外沿允许最多 12 个输出像素的补绘像素反射延拓，以吸收轻微仿射偏移。延拓范围和像素数写入每块报告，不采用原图细节填洞，也不改变单一仿射变换。较大的覆盖缺口会导致检查失败。透明结果保留原图透明轮廓。

原图局部的 SIFT 特征不足时，在补绘前停止。每块补绘原生宽高至少达到该块目标的 75%，否则拒绝靠大幅插值冒充超分；图像工具的实际分辨率不足时，需要降低倍率或使用较小原图。

调用设置中可以编辑「超规格拼接 · 系统提示词」，支持 `{prompt}`、`{tile_index}`、`{tile_count}`、`{bounds}`、`{target_size}`。整个调用模板随任务固定。默认模板已写入上述工作流、主模型细化要求和预装环境说明。

## 进度与重试

任务显示原图、切图、补绘、配准、色调、接缝、融合、局部检查和回传九个阶段，以及已完成块数和当前 CLI 子阶段。进度百分比根据已完成阶段和块数计算，表示工作量进度，不预测剩余时间；AI 调用未返回时保持真实进度并显示流动状态。数值变化采用缓动过渡。

每块独立保存。手动重试会复用已有原图、补绘块、配准及计算检查点，避免把完成的工作全部重跑。取消会终止当前 CLI 或计算进程，保留工作文件。视觉检查未通过时保留候选图和问题报告，不发布为成功；再次重试会重新进行视觉检查。若需要重新补绘全部内容，可用「再抽一张」新建一轮任务。

新创作通常需要 1 次原图生成、n 次局部生图和 1 次视觉检查；发送已有图片则省去原图生成。网络或配准失败可能触发额外补绘，受任务的最大尝试设置约束。

## 环境与资源

安装脚本固定安装 `numpy==2.2.6`、`opencv-python-headless==4.13.0.92`，并检查 SIFT、Graph Cut 与 MultiBandBlender。计算直接由工作台使用虚拟环境 Python 执行，模型无需安装包、写脚本或运行 shell。

服务端给 CLI 提供 `STUDIO_STITCH_PYTHON` 和 `STUDIO_STITCH_ENGINE` 环境变量；运维入口是：

```bash
image-studio-stitch --help
```

计算进程单独运行并限制 CPU 线程，重型计算串行执行；不同任务的 CLI 仍遵循工作台并发设置。画布使用磁盘映射并分块融合。当前限制最终结果不超过 6400 万像素，单边小于 32700px；已有作品在提交前验证，新原图在生成后、补绘前验证。超限会说明原因，不会静默降低倍率。

算法报告和工作图都受工作台登录保护，存放在私有任务目录。仓库测试使用合成纹理验证 4×、9×、16× 的裁切、仿射、色调、图割和融合，以及模拟 CLI 的完整调度与取消恢复；这些测试不代表真实模型能完美保留所有画面结构。
