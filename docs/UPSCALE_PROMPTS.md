# 超分提示词：快照、范围与实际调用

新任务使用 `upscale_prompts.py` 的 schema 2 编译器。预览和执行调用同一编译器，超分不再借用普通生成的外层模板。这里的“实际发送”是工作台送入 CLI 的完整文本；工作台无法获取生图工具内部未公开的提示词。

## 七类设置

| 设置 | 生效范围 |
| --- | --- |
| 图像调用与产物协议 | 附件、目标原生尺寸、透明背景、阶段反馈、真实图片产物 |
| 图块超分系统提示 | 本级当前图块的保真增强与接缝要求，可在入口关闭 |
| 任务统一要求格式 | 用户填写的全局细节、材质或画风要求，各级一致 |
| 历史背景格式 | 明确开启后附带原图描述，只作背景，不重新执行历史编辑 |
| 选块修复系统提示 | 本级所选图块的局部修复，可选择任务快照或当前设置 |
| 单块重试反馈 | 当前调用真实失败原因，只用于修正本块返回 |
| 视觉验收系统提示 | 对照本级输入、结果与检查局部，区分统一要求和局部范围 |

模板变量只替换一次，用户正文中的 `{...}` 不会再次作为变量解析。设置保存会校验必需变量及未知变量，失败保留正在编辑的文本。

## 提交与重试

专用超分页、图片快捷超分、生成后超分都明确选择 `append_system` 和 `include_source_context`。关闭前者仅跳过图块创作系统模板，必要的产物协议、尺寸与独立验收仍在。历史背景默认关闭。

提交时冻结全部模板、开关与版本。预览返回版本；提交携带该版本时，设置已变化会返回 409，要求重新预览。生成后自动超分的子任务继承父任务的冻结配置，原图背景使用实际保存的润色正文（有记录时）。

统一要求不能原地改写已冻结任务。任务详情可复制为新任务，带上原图、倍率、要求和开关，采用当前系统模板，不混入旧任务的图块。普通重试沿用原快照。

## 失败修复

`repair_scopes` 记录修复 ID、级别、所选块、要求及修复模板来源。局部要求只附加到本级所选块；后续级读取修复后的整图，不继承局部编辑命令。选择最新修复模板不会更新原任务的全局超分/验收模板。关闭局部修复模板时，仍保留用户填写的修复要求。

未选中的成功返回继续复用。选中块的旧返回和来源记录归档，再使其派生配准、融合及后续级失效。缓存身份包含输入及任务执行配置；每块保存来源与修复 ID，不能仅凭文件存在就宣称属于新版本。

## 查看记录

- `/api/assets/{id}/upscale-prompt-preview`：填入真实图块尺寸与作用域的完整预览。
- `/api/upscale/jobs/{id}/prompt-snapshot`：任务冻结配置与修复范围。
- `/api/upscale/jobs/{id}/calls`：实际留存调用的分页目录。
- `/api/upscale/jobs/{id}/calls/{call_id}`：该次完整指令、组件、变量、版本与作用域。

以上接口需要现有登录，写请求仍受 CSRF 保护。列表只返回轻量摘要，完整模板从详情读取。旧任务缺少完整快照时明确提示，只展示真实留存记录；清理任务缓存也会移除相应中间调用文件。
